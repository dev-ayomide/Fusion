# Fusion Motion

An AI-native motion-graphics editor. A whole video is one JSON document (FMD); the browser evaluates it
live with Three.js; people and AI agents edit it with the same small, reviewable, undoable ops.
Standalone: no Remotion, not part of the root workspaces.

```bash
cd motion
npm install
npm run dev        # http://localhost:5180
npm test           # unit + property tests (schema, ops/inverses, evaluator, eases)
npm run e2e        # Playwright end-to-end tests (editor, AI bridge, export, AE-style controls)
npm run bench      # token benchmark → docs/TOKENS.md
npx tsx e2e/record-session.ts out/   # records the full user lifecycle to out/session.webm
npx tsx e2e/record-pear.ts out/      # walkthrough of the Pear replica + AE-style tools
python bench/quality.py …            # replica-vs-reference metrics (docs/QUALITY.md)
```

## AI setup

Put a key in `motion/.env` (gitignored; picked up without a restart). The editor connects automatically on load,
in this order:

```bash
ANTHROPIC_API_KEY=sk-ant-…     # Claude Opus 5.5 (preferred)
AGENTROUTER_API_KEY=…          # DeepSeek via AgentRouter
MISTRAL_API_KEY=…              # Mistral
```

Keys stay on the Vite dev server, which proxies `/api/<provider>` and attaches them — they never reach the browser.
Switch models from the pill at the top of the Assistant; `?ai=off` disables auto-connect. External agents can still
drive everything through `window.fusion.bridge` (see `docs/AGENT-FLOW.md`).

## What's in the box

- **Landing page** — describe the video, attach a logo/screenshots, or pick a template (thumbnails are rendered live).
- **Your videos** — every project autosaves to a library in this browser (IndexedDB) with a live-rendered thumbnail;
  reopen, rename, duplicate or delete from the landing page, or via "Your videos" in the editor's top bar.
- **Storyboard first** — a prompt returns a scene plan (titles, briefs, durations) before anything is built. Edit,
  reorder, add or delete scenes and set length/format/look, then press Build: the AI sets the look once and builds one
  scene at a time (each one undo step). Queued scenes stay editable while earlier ones build. See `docs/AGENT-FLOW.md`.
- **Music** — a music lane on the timeline: pick from bundled CC0 tracks (generated by `bench/music-library.mjs`,
  free to use anywhere) or upload your own (MP3/WAV/M4A/AAC/OGG/WebM). Trim, move, volume, fades, mute, fit to the
  video; plays in sync with the preview and is mixed into the export.
- **Simple mode** — chat, vibe sliders (energy · bounce · depth), zero-token tweak chips, one-click entrance/loop/exit presets.
- **Pro mode** — layers panel, keyframe stopwatch on every channel (auto-key), behaviour cards with spring/ease/params,
  bake-to-keys, expressions, parenting, 3D depth-sort switch, JSON editor, "what the AI sees" outline.
- **Viewport** — click to select, drag to move (auto-keys if the channel is keyed), double-click text to edit,
  drop images (onto a device to use as its screen), Shot/Split view with an orbitable scene camera and the shot frustum.
- **Timeline** — canvas dopesheet: layer bars (drag, trim edges), behaviour clips coloured by kind (drag, resize),
  key lanes (drag, double-click to add, ⌫ to delete), snapping to playhead/edges/frames (Alt to disable),
  ⌘-wheel zoom, pinned orange camera lane, playhead outside React.
- **Assistant** — prompts become pending turns carrying only the outline + scoped layers. Any agent answers through
  `window.fusion.bridge`; ops stream into a live preview with a per-op accept/reject diff card; one undo per turn.
  Paste ops from any AI in Pro mode.
- **After Effects muscle memory** — F9 / ⇧F9 / ⌘⇧F9 Easy Ease, ⇧F3 graph editor with bézier handles, AE keyframe
  icons, J/K keyframe navigation, U reveal, comp motion-blur switch, Effect Controls (blur, drop shadow, glass).
- **Premium finish** — temporal motion blur, bloom, grade, vignette, grain; layer blur, frosted glass, soft shadows,
  clip masks, adjustment layers with white-outs and cloud dissolves.
- **Rich layers** — HTML/CSS UI cards with keyable counters, chart lines with trim paths, PBR 3D meshes under HDRIs
  (chrome, foil, glass…), procedural skies/mountains/meadows, styled text runs with script accents and write-ons.
- **Asset library** — 24 bundled 3D objects (Fluent 3D emoji), 10 HDRI environments, 12 font families.
- **Export** — MP4/WebM at 720p/1080p/4K, rendered frame-by-frame in the browser by the preview renderer
  (mediabunny + WebCodecs; picks H.264 where the browser has it, else AV1/VP9).
- **History / undo** — every change (you, AI, slider, JSON edit) is one transaction; jump back from the History tab.
- Autosave to localStorage, assets in IndexedDB.

## Layout

```
src/fmd/       schema (Zod 4), catalog, paths, ops engine (macros → set/del/ord, inverses, validation), outline
src/runtime/   ease + normalized spring, seeded noise, expression interpreter, evaluate(doc, t)
src/render/    Stage: SDF quad material, per-glyph text, PBR device mockups, cloners, gradient, camera, picking
src/editor/    store (op log, preview, transient drags), playhead, bridge, components (Viewport, Timeline, Inspector, Assistant, …)
src/export/    mediabunny exporter
e2e/           Playwright suites, session recorder, fixtures
docs/          PLAN-v2 (verbatim), PLAN-DELTA, FMD-SPEC, TOKENS, ARCHITECTURE, MOTION-DESIGN, QUALITY
fixtures/pear/ the Pear breakdown replicated as four FMD docs (+ generator)
bench/         token benchmark, quality metrics, frame renderer
```

Keyboard: Space play · ←/→ frame · ⌘Z/⇧⌘Z · ⌫ delete · ⌘D duplicate · T/R/E add text/rect/ellipse ·
[ ] in/out to playhead · S split · P simple/pro · / ask AI · ? all shortcuts.
